# Gemini App to Retrieve SQL Data

A Python application that uses Google Gemini to convert natural-language questions into SQL queries and retrieve data from a SQLite database.

## Features

- Ask questions about database records using natural language.
- Generate SQL queries using Google Gemini.
- Execute SQL queries against a SQLite database.
- Display query results in an easy-to-understand format.
- Includes a sample student database.
- Simple and beginner-friendly implementation.
